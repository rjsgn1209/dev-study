# 세마포어

세마포어는 커널 객체이기 때문에 파일하나를 열어 컨트롤 하는 정도의 부하가 발생하므로 느리다.
  
그렇기에 일반적인 동시성 확보를 위해서는 CriticalSection을 사용한다.
  
하지만 CriticalSection은 한 구문에 하나의 스레드만 접근할수있게 했다면 세마포어는 한구역에 동시에 n개의 스레드가 접근할수있도록 해준다.
  
일반적인 Client 앱 개발 할때는 사용되지 않지만 Client/Sever 구조에서 개발 시 사용되는 경우가 많다.
  
DB같은 경우가 대표적인 세마포어 활용의 사례인데
  
여러 클라이언트가 서버를 통해 DB에 접근 하게될때 채널의 갯수만큼의 클라이언트의 접근을 허용하여 데이터를 제어할수 있게 해야만하는데 
  
이런 경우 세마포어를 사용하게된다.
  
세마포어의 사용법은 이벤트 방식과 동일하나 하나의 세마포어를 통해 여러 스레드의 동시 접근을 제어할수있다는 차이가 있다.
