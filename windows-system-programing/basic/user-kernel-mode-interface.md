# User mode와 Kernel mode Interface

## User mode / Kernel mode
윈도우즈 운영체제에서는 유저모드와 커널모드 두 가지의 모드가 존재한다.
  
유저모드는 인강의 영역 커널모드는 신의 영역이라 할수있을 정도로 강력하게 나누어져있다.
  
일반적으로 유저모드에서 커널모드로 접근하기 위해서는 파일을 통해서 접근하게되는데 해당 파일에 접근하는 주체는 프로세스이다.
  
프로세스는 파일을 통해 운영체제에 엑세스하게되며 특정 프로세스 가진 권한에 따라 접근을 운영체제 측에서 허용/차단 할수있으며
보안관련 학습을 위해 커널모드 학습은 필수적이다.

## 파일 File
파일이란 것은 우리가 일반적으로 생각하는 .doc, .mp4와 같은 데이터 형태의 파일도 존재하지만 
장치, 커널의 구성요소가 추상화된 인터페이스 형태의 파일로도 존재하게 되며
운영체제를 제어하기 위한 하나의 인터페이스 역할을 하게되는것이다.
