# 이벤트 동기화

스레드에서 특정 시점을 다른 스레드에 알리고싶다면 Event 객체를 사용하여 동기화를 하게된다.

## 이벤트 동기화 방법
  
메인 스레드에서 이벤트를 생성하고 워커 스레드로 해당 이벤트를 넘긴다.
  
메인 스레드에서는 해당 이벤트를 기반으로 WaitForSingleObject 함수를 호출하여 Wait하고 
  
워커 스레드에서는 특정 시점 까지 작업 후 넘겨 받은 이벤트를 SetEvent 하여 메인 스레드의 Wait상태를 변경하게된다.
  
## 이벤트 동기화 유의사항

SetEvent 생성 시점에서 수동 리셋을 파라미터를 통해 설정이 가능한데 
  
일반적으로는 FALSE를 인수로 사용하여 WaitForSingleObject 함수 호출 할 때 
  
ResetEvent 함수가 호출되게 하지만 수동 리셋을 TRUE로 줘야 만 하는 경우가 있다.

생성된 이벤트를 여러 스레드에서 한번에 Wait하게 되면 
  
해당 이벤트가 Set 되었을때 하나의 스래드에서 받아서 처리하며 Reset 해버리게 되고 
  
이런 경우 나머지 스레드들은 Wait 상태에서 벗어나지 못하게된다.
  
위 같은 특정 상황에서는 수동리셋를 TRUE로 하여 이벤트를 사용할수있다.
  
또한 이벤트(커널 객체) 생성 시 이름을 입력할 수 있는데
  
일반적으로 프로세스 내부에서 사용할때는 NULL을 주로 인수로 주게 되지만 
  
프로세스간의 동기화에서는 이름 명시하여 동기화를 진행하게된다.
