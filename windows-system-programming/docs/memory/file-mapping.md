# 파일 매핑 및 메모리 추상화

파일과 메모리(RAM)는 다른것 처럼 보이지만 같은것 처럼 사용할수도있다.
  
가상메모리는 RAM + HDD(SDD) 이다
  
32bit 프로세스에서는 2에 32승(4GB) 정도의 메모리를 쓸수있는데
  
일반적으로 4GB의 나누어 2GB는 User, 2GB는 Kernel 영역으로 사용되게된다.
  
일반적으로 커널 영역의 메모리에 유저가 접근하게되면 접근 에러가 발생하게된다.
  
하지만 파일에 대한 매핑객체를 만들어 커널영역에 존재하는 메모리를 추상화하여 포인터로 접근할수있다.
  
파일에 대한 매핑객체를 만들고 해당 매핑 객체를 프로세스의 가상 메모리 공간에 맵핑시킴으로써 포인터를 받게된다.
  
해당 포인터는 커널영역의 파일 메모리를 가르키게되는데 수정하게되면 커널 메모리 영역의 파일 또한 동일하게 수정되게된다.
  
위와 같은 과정으로 두 파일의 포인터를 받아와 memcpy를 하게되면 간단하게 파일을 복사할수도있다.
