# Acess Token과 프로세스 권한 상속

행위의 주체는 항상 프로세스(스레드)이다.
  
원도우즈 실행 시 보여지는 로그인 창도 하나의 프로세스가 실행중인 것이고 
로그인을 통해 보여지는 윈도우즈 바탕화면 또한 로그인 프로세스가 실행한 하나의 프로세스이며
탐색기(쉘 프로세스)라고 부른다.
  
윈도우즈 로그인 시 해당하는 계정에 대한 권한을 쉘 프로세스에 부여하게 되며 
해당 권한은 Access Token(구조체)의 형태로 존재 하게되고 
대표적인 정보로 SID 정보를 통해 권한을 식별하게된다.
  
이후 탐색기를 통해 새 프로세스를 생성하게되면 동일한 권한이 상속되게된다
  
일반유저로 로그인된 계정에서 관리자권한을 필요로 하는 프로세스를 실행시키고 싶을때 
시스템 서비스의 취약점을 공격하여 관리자 권한을 가진 프로세스를 실행시켜 계정을 만들게 할수있는데
다음과 같은 행위를 원격보안 실행 취약점이라는 하나의 해킹기법이다.
  
CreateProcess 함수를 통해 프로세스를 실행 시 
NULL 입력 된 파라미터들은 해당 함수를 호출한 프로세스가 가지고 있는 값들을 상속 받게된다는 의미이다.
  
CreateProcessAsUser 함수를 통해 외부 프로세스의 토큰을 가져와 외부 프로세스 정보를 기반으로 실행할수도 있다.
