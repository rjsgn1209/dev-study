# 파일 기본 개념

프로세스는 주체이고 파일은 대상체이다.
  
프로세스는 파일은 읽고/쓰고/실행 하게된다.
  
파일은 데이터, 인터페이스 형태로 존재한다.
  
메모리에는 1차 메모리 RAM, 2차 메모리 SSD(HDD)가 있는데 파일은 2차 메모리에 기본적으로 저장되게된다.
  
   
- 물리 드라이브 : 1TB 하드 디스크  
- 논리 드라이브 : 파티션 불리하여 C 드라이브 512GB, D 드라이브 512GB 분리
  
디렉토리는 폴더 이고 디렉토리가 나오면 항상 경로가 따라 나오는데 경로에는 절대 경로, 상대 경로가 있다.
  
- 절대 경로 : C:\Data\Sub\a.dat
- 상대 경로 : .\a.dat(현재 경로 기준)
  
  
- . = 현재 경로 기준  
- .. = 상위 경로 기준
