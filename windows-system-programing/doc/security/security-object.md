# 보안 객체 와 기술자

## 보안객체 
- 파일과 폴더
- 프로세스와 스레드
- 파일매핑 객체
- 파이트
- 토큰
- 윈도우 스테이션 및 데스크톱
- 레지스트리
- 서비스
- 프린터
- 네트워크 공유자원
- 이벤트, 뮤텍스, 세마포어
  
보안객체에는 다음과 같은 항목들이 존재하며 Windows에서 접근 권한을 검사해야하는 대상을 말한다.

## 보안 기술자
보안객체에 대한 보안과 관련된 정보가 담긴 구조체 이다.
  
파일이나 폴더 생성 시 접급 권한에 관한 정보가 함께 생성되며 
주체(프로세스)가 가진 권한에 따라 파일에 접근에 대한 권한이 상속되게 된다.
  
유저모드에서의 보안권한은 SYSTEM > Administraters > Authenticated Users > User 순으로 강력한 권한을 갖는다.
  
주체의 보안 권한에 따라 파일의 읽기, 쓰기, 실행과 같은 권한을 부여받을수 있다.

## DACL
보안객체에는 DACL이 존재하며 DACL은 보안객체에 대한 프로세스의 접근 허용/차단 정보를 가진 데이터 구조이다.
  
DACL은 ACL(Access Control List)의 리스트 이며 ACL은 ACE(Access Control Entry)의 리스트 이다.
  
ACE는 윈도우 시스템의 접근제어를 위한 기본정보이며 ACE의 핵심 정보는 SID(Security IDentifier)이다.
  
SID는 그룹에 대한 SID, 사용자 계정에 대한 SID가 개별적으로 존재하며
보안객체에 대한 DACL에는 어떠한 SID에 대해 어떤 권한을 부여할지 기술되어있다

## SACL
보안 객체에 대한 접근 로그를 남기는 근거 정보

## 정리
프로세스(주체)가 보안객체에 접근할때 프로세스의 보안토큰 내부에 SID값과 매칭되는 보안객체의 DACL에 저장된 SID 권한(RWX)을 운영체제가 부여하여 해당 보안객체를 주체가 제어할수 있게된다.
