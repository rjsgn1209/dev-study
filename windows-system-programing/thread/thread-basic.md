# 스레드 기본 개념

## 스레드 정의

프로세스 하나에는 항시 스레드가 하나 존재하게되며 스레드는 실행의 최소단위가 된다.
  
스레드는 CPU의 코어를 점유하며 동작하게되고 하나의 연상 과정이된다.
  
프로세스 내부의 스레드가 하나면 싱글 스레드 두개 이상이면 멀티 스레드이다.
  
모든 스레드는 자신이 속한 프로세스의 가상메모리 공간을 공유하고 개별화된 스택을 가지며 기본적으로 1MB의 스택 공간을 갖는다.

## 스레드 속성

- ID와 핸들
- 우선순위(Highest, Above normal)
- 상태(Run, Suspended, Terminated)
- 친화력(CPU core) 특정 코어 사용 지정

## 스레드 동작 방식

Run 상태의 스레드는 CPU를 할당 받기 위해 RunQueue에서 대기하며 운영체제에의해 CPU 자원을 할당받게된다.
  
메인 스레드에서는 일반적으로 UI 갱신 동작을 한다.
  
기본적으로 메인 스레드가 존재하고 메인스레드에서 추가로 생성되어 동작하는 스레드를 워커 스레드 라고 부른다.
  
워커 스레드에서는 파일 입출력과 같은 많은 시간이 소요되는 작업을 분리하여 작업함으로써 메인스레드의 UI가 멈추는 현상을 방지할수있다.

## 멀티 스레드를 사용하는 경우

GUI 프로그램의 UI 갱신/ 파일 입출력
  
DB 대용량 자료입출력 시 Prograss bar UI처리/ DB 데이터 송수신
  
실시간 영상 전시 시 영상 재생/ 영상 정지,재생 UI처리/ 서버와 데이터 송수신

## 멀티 스레드 사용 시 주의사항

멀티스레드가 되는 순간 프로세스에서 우연이 생겨나며 예측하지 못한 에러가 발생할수있다.
  
생성된 스레드는 특정 함수가 아닌 return을 통해 자연스럽게 종료되는게 가장 좋다.
