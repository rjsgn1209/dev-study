# 스레드 제어

스레드 제어를 위해서는 해당 스레드의 핸들과 해당 핸들을 제어하기위한 권한이 필요하다.
  
스레드의 핸들을 통해 일시정지 하거나 재시작할수있다.
  
메인 스레드에 의해 생성된 작업자 스레드는 항시 메인 스레드보다 먼저 종료되어야한다.

## 스레드 상태

- Running : CPU 자원 할당 중
- Suspanded : 일시정지
- Terminated : 삭제

## 스레드 스위칭

스레드의 상태를 변경하게 되면 스위칭이 발생하고 그로 인한 오버헤드가 발생한다.
  
스위칭이란 스레드 변경 과정에서 기존 스레드의 작업 상태를 저장 하여 레지스트리에서 RAM으로 백업을 하게되고 
CPU 할당을 받아 작업을 시작하게되는 스레드의 작업 상태를 RAM에서 레지스트리로 복원 하는 과정을 거치게 되는데 
해당 과정에서 오버헤드가 발생한다.
