# 임계영역 동기화

일반적 동기화라고 하면 임계영역 동기화를 많이 사용한다.
  
Linked List와 같이 동시에 읽기/쓰기를 하게되면 위험한 객체에 여러 스레드가 동시에 접근 할때 에러가 발생하지 않도록 무결성을 보장해야한다.
  
특정 포인터에 메모리를 동적 할댕/해제 할때 동시에 여러 스레드에서 할당/해제를 반복하게되면 해당 포인터에서 메모리 에러가 발생하게되는데

## 임계영역 설정 이유

일반적으로 디버그 모드일때 해당 포인터를 할당하게되면 할당된 메모리 영역의 앞뒤에 
  
해당 메모리에 대한 침범을 검사하기 위해서 특정 값이 입력되게 되는데
  
메모리를 해제하는 과정에서 해당 지점에 변동사항이 없는지 검사하게 되고 이상이 있을 시 메모리 에러가 발생 하게 된다.
  
다음과 같은 메모리 동시 제어로 인한 에러를 방지하기 위해 일반적으로 Critical section 객체를 사용하게된다.

## 임계영역 활용 방법

Critical section 객체는 특정 영역에 대한 스레드 접근 시 Lock을 걸어 한번에 여러 스레드가 동시 접근할수 없도록 차단하는 역할을 하게되는데
  
Initialize을 통해 생성된 CS객체를 임계영역으로 지정하고자 하는 시작 지금에서 Enter 함수의 인자로 전달하여 Lock을 걸게하고
  
작업 후 임계영역이 끝나지 지점에 Leave 함수의 인자로 전달하여 Unlock을 하게된다.

## 임계영역 동기화 유의사항

위와 같은 과정을 하나의 CS객체를 가지고 여러 스레드에서 작업하여 동시접근에 대한 무결성을 보장하게되는데
  
임계영역을 무분별하게 사용하게되면 Dead lock과 효율저하가 발생 할수있다
  
그렇기에 임계영역은 필요한 구역에 최소한으로 사용 하는것이 좋다.
